= Ammitto UK sanctions data

image:https://github.com/ammitto/data-uk/actions/workflows/fetch.yml/badge.svg["Fetch Data", link="https://github.com/ammitto/data-uk/actions/workflows/fetch.yml"]

This repository stores the UK Sanctions List as YAML for Ammitto. The
Foreign, Commonwealth and Development Office (FCDO) publishes the official
list; Ammitto generates one file per designated person, entity or ship in
`processed/`.

== Source

* Publisher: Foreign, Commonwealth and Development Office (FCDO)
* List page: https://www.gov.uk/government/publications/the-uk-sanctions-list
* File downloaded (XML): https://sanctionslist.fcdo.gov.uk/docs/UK-Sanctions-List.xml

The list shows which people, entities and ships are designated or specified
under regulations made under the Sanctions and Anti-Money Laundering Act 2018,
and why. Since the OFSI Consolidated List closed on 28 January 2026, it is the
only source for UK sanctions designations.

== Contents

`processed/` holds one file per designation, named after its unique ID in
lower case: `processed/afg0001.yaml` is `AFG0001`. The letters are the regime,
such as `rus` for Russia.

`processed/_index.yaml` lists every file, with the time of the last fetch.

[cols="1,1,3"]
|===
| Key | Type | Meaning

| `unique_id` | string | UK Sanctions List unique ID, such as `AFG0001`
| `ofsi_group_id` | string | OFSI group ID, where one exists
| `un_reference_number` | string | UN reference number, where one exists
| `individual_entity_ship` | string | `Individual`, `Entity` or `Ship`
| `regime_name` | string | The sanctions regulations, such as `The Russia (Sanctions) (EU Exit) Regulations 2019`
| `designation_source` | string | `UK`, `UN` or `UK\|UN`
| `date_designated` | string | Date of designation, `YYYY-MM-DD`
| `last_updated` | string | Date the entry last changed, `YYYY-MM-DD`
| `names.names` | list | Names: `name_type` (such as `Primary Name`, `Primary Name Variation` or `Alias`, in varying case), `alias_strength` where given, and the name parts `name1` to `name6`. Usually, for individuals, `name1` to `name5` hold given and middle names and `name6` the family name, and for entities and ships `name6` holds the name. A few name entries are empty.
| `non_latin_names.names` | list | Names in non-Latin scripts, as `name_non_latin_script`
| `addresses.addresses` | list | `address_line1` to `address_line6` and `address_country`
| `sanctions_imposed` | string | The sanctions, as published, such as `Asset freeze`
| `sanctions_imposed_indicators` | map | True or false for the sanctions that have an indicator in this file: `asset_freeze`, `travel_ban`, `arms_embargo`, `targeted_arms_embargo`, `trust_services_sanctions`, `director_disqualification_sanction`, `chartering_of_ships`, `crew_servicing_of_ships_and_aircraft`, `prevention_of_chartering_of_ships_and_aircraft`, `prevention_of_business_arrangements`, `closure_of_representative_offices`, `technical_assistance_related_to_aircraft`, `deflag`
| `uk_statement_of_reasons` | string | The UK statement of reasons
| `other_information` | string | Further information published with the designation
|===

`sources/` holds a hand-curated sample entry and supporting reference data
(document types, organisations), with their schemas in `schemas/`. The daily
fetch does not update it; `processed/` is the list.

== Using the data

Clone or download this repository and run either example from its root
directory. The Python example requires PyYAML
(`python3 -m pip install PyYAML`).

Ruby:

[source,ruby]
----
require "yaml"

Dir.glob("processed/*.yaml").sort.each do |path|
  next if File.basename(path) == "_index.yaml"

  record = YAML.safe_load_file(path)
  name = record["names"]["names"].find { |n| n["name_type"].casecmp?("Primary Name") }
  text = name && (1..6).map { |i| name["name#{i}"] }.compact.join(" ")
  puts [record["unique_id"], record["individual_entity_ship"], text].join("\t")
end
----

Python:

[source,python]
----
import glob
import os
import yaml

for path in sorted(glob.glob("processed/*.yaml")):
    if os.path.basename(path) == "_index.yaml":
        continue
    with open(path, encoding="utf-8") as f:
        record = yaml.safe_load(f)
    names = record["names"]["names"]
    name = next((n for n in names if n["name_type"].lower() == "primary name"), None)
    text = " ".join(name[f"name{i}"] for i in range(1, 7) if name.get(f"name{i}")) if name else ""
    print(record["unique_id"], record["individual_entity_ship"], text, sep="\t")
----

== Updates

The `Fetch Data` workflow (`.github/workflows/fetch.yml`) downloads the list
every day at 06:00 UTC and commits any change to `processed/`. It runs with
`--prune`, so a designation the FCDO has removed is deleted here on the next
fetch.

== Maintaining the data

The link:.github/workflows/fetch.yml[fetch workflow] uses Ruby 3.4 and Bundler.
To refresh `processed/` locally, install the link:Gemfile[Gemfile] dependencies
and run the same command from the repository root:

[source,shell]
----
bundle install
bundle exec ammitto fetch uk --format yaml --output-dir processed --verbose --prune
----

This regenerates `processed/` and removes entries absent from the fetched
list. Fetching and parsing are implemented in the
https://github.com/ammitto/ammitto[Ammitto gem].

For edits to the curated samples and reference data in `sources/`, run
`bundle exec rake validate`. The link:Rakefile[Rakefile] checks only those
source files against `schemas/`.
